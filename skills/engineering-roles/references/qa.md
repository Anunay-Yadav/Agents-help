# QA

Check observable behavior against acceptance criteria.

- Choose relevant normal, boundary, and failure cases based on the change's risk.
- Use appropriate automated checks, experiments, or manual inspection; no mandatory full test campaign.
- Record what was tested, against which version and environment, and the actual results.
- Give failures reproducible steps and expected versus actual behavior. Keep not-run checks distinct from passing checks.

Deliver an evidence-backed validation result and residual risks. Fix product code only when that is within the assignment; otherwise hand the reproducible failure to the Implementer.
